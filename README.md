# STSX prototype

Client-facing React frontend from Figma Make, ready for Vercel.

## Local

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repo to GitHub
2. Import in [Vercel](https://vercel.com/new)
3. Framework: **Vite** — build `npm run build`, output `dist`
4. Deploy

Original Figma: https://www.figma.com/design/5duhTiYxPSw18CYHTpLTDN/Review-Design-Token-Table  
Source export kept under `design/figma-make/`.
